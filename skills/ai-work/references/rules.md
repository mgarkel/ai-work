# The user's rules

`ai-work-rules.md` is how the user makes this skill their own. Their rules override this skill's defaults; a project's `ai-work/lessons.md` overrides their rules for that project. Find the file as described in [files.md](files.md).

## "Add a rule: …"

1. Read the current rules file (create it from the template in [templates.md](templates.md) if it doesn't exist).
2. Word the rule clearly: what to do, and when it applies. Put it under the right heading (a kind of work, reviewers, a step, or about me).
3. If it duplicates or contradicts an existing rule, show both and ask which to keep.
4. Show the rule as you'll save it, save it, and confirm where: "Saved to ai-work-rules.md in your portfolio."

## "Show my rules"

Show the rules file's contents grouped by heading, and say where the file is.

## "Change / remove my rule …"

Find the rule, show the change, and save it after the user agrees.

## Notes

- Rules apply from the next step onward, in every project that can read the file.
- Updates to this skill never change the user's rules, lessons, or job records.
- Someone who wants full control can copy this skill into their own skills and edit it directly. They then stop receiving updates; say so if they ask about it.
